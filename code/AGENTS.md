- **布局模式**: 上下分区 + 卡片式布局 —— 各功能模块独立成区，每区内根据功能特点采用单栏或左右分栏

## 功能列表

### 区块：薪资预测计算器 (#salary-predict)

- **页面目标**: 用户输入个人背景信息，一键获取预期薪资区间与档位判定
- **功能点**:
  - **岗位方向选择**: 大数据岗位 / IT 岗位二选一单选切换，影响后续技能选项和薪资基准
  - **背景信息表单**: 目标城市下拉（20 个城市）、学历下拉（4 档）、工作经验下拉（6 档）、已掌握技能多选标签（按编程语言/数据库/大数据框架/分析工具/云服务分组）
  - **薪资预测计算**: 点击"预测薪资"按钮，基于基准矩阵 + 技能加权计算薪资区间和档位
  - **结果展示卡片**: 展示预期薪资区间（下限K-上限K）、薪资档位徽章（低薪/中薪/高薪）、同档位人群画像特征说明
  - **表单实时校验**: 必填项校验、技能选择数量提示、悬停反馈与过渡动画

### 区块：技能提升规划器 (#skill-planner)

- **页面目标**: 基于用户当前技能和目标，输出最优学习路径与技能优先级
- **功能点**:
  - **目标参数配置**: 可用学习时间选择（1个月/3个月/6个月）、目标薪资涨幅滑块或输入
  - **技能匹配与排序**: 自动读取薪资预测模块的已选技能作为当前技能，计算未掌握技能的投入产出比并排序
  - **优先学习清单展示**: 按 ROI 排序的技能列表，每项显示预期薪资提升幅度、学习难度、预计掌握时间
  - **分阶段学习路径**: 根据学习时间生成分阶段学习计划（基础期/进阶期/冲刺期）
  - **技能薪资溢价排行榜**: 独立参考卡片，展示全量技能薪资溢价 TOP 榜单

### 区块：城市与岗位决策助手 (#decision-helper)

- **页面目标**: 用户设置偏好权重，获取个性化的城市与岗位推荐
- **功能点**:
  - **偏好权重配置**: 4 个维度滑块（薪资水平、岗位需求量、成长空间、生活成本），实时显示权重占比
  - **城市综合排名**: 根据权重计算各城市综合得分，展示 TOP5 城市卡片
  - **岗位赛道推荐**: 同理计算各岗位类型（数据开发/数据分析/数据治理等）综合排序
  - **优劣势对比分析**: 展示 TOP3 选项的多维度对比雷达图或对比表格，标注各选项核心优势与劣势

### 区块：数据可视化看板 (#data-dashboard)

- **页面目标**: 展示行业整体数据洞察，增强网站可信度与参考价值
- **功能点**:
  - **城市平均薪资排行**: 横向条形图，展示 19 个城市平均薪资排名
  - **学历与薪资热力图**: 热力图展示学历×经验/城市的薪资分布
  - **工作经验薪资增长趋势**: 折线图展示不同经验阶段的薪资增长曲线
  - **高频技能 TOP 榜单**: 条形图或标签云展示出现频率最高的技能 TOP10
  - **岗位类型分布占比**: 环形图展示各岗位类型的样本数量占比

# UI 设计指南

## 1. 设计推导依据

- **参考意图**: Free Direction —— 附件为研究文档与分析代码，仅提供业务数据语义，不约束视觉与布局。
- **核心情绪 / 应用类型**: 面向 IT/大数据求职决策工具，以数据驱动的精准感与专业可信度为核心情绪。
- **独特记忆点**: 薪资数字以"数据仪表式等宽字体呈现，配合深蓝渐变光晕锚点与细网格底纹，强化"数据预测"的精密感。

## 2. Art Direction

- **方向名**: 深蓝数据仪表
- **Design Style**: Swiss Minimalist + Modern Dark Accent —— 瑞士极简的网格秩序与克制排版，叠加数据仪表式的数字高亮与渐变光晕，契合大数据薪资预测的专业、精准、高级商务气质。
- **DNA 参数**: 圆角 subtle (rounded-md) / 阴影 subtle (shadow-sm) / 间距 standard (gap-4 / p-6) / 字体方向 无衬线正文 + 等宽数字 / 装饰手法 细网格底纹 + 渐变光晕 + 细线分隔
- **应用类型**: Tool + Dashboard 混合 —— 首屏工具主导，下方分区数据看板与决策工具并列

## 3. Color System

**色彩关系**: 深空蓝灰基底 + 冷蓝主色 + 青蓝渐变点缀 + 纯白卡片面
**配色设计理由**: 深蓝/深灰主色调建立高级商务与科技数据感；冷蓝 primary 承担预测按钮与关键数字高亮；青蓝渐变用于薪资区间、图表高亮和状态徽章；大面积留白保证表单与数据的可读性。
**主色推导**: 从大数据与 IT 行业的"数据海洋""科技深蓝"语义出发，选取高饱和冷蓝作为 primary，搭配同色系青蓝作为 accent 渐变，形成冷静但不沉闷的商务科技调性。
**使用比例**: 65% 中性（深灰底 + 白卡 + 墨色文字）/ 25% 辅助（accent 浅底、边框、网格）/ 10% primary（CTA、关键数字、品牌锚点）。

| 角色 | CSS 变量 | Tailwind Class | HSL 值 | 设计说明 |
|---|---|---|---|---|
| bg | `--background` | `bg-background` | hsl(215 28% 10%) | 深空蓝灰页面背景，营造数据沉浸感 |
| card | `--card` | `bg-card` | hsl(215 25% 14%) | 深灰卡片面，略亮于背景形成层次 |
| text | `--foreground` | `text-foreground` | hsl(210 20% 96%) | 近白正文，高对比可读 |
| textMuted | `--muted-foreground` | `text-muted-foreground` | hsl(215 12% 60%) | 次级说明文字，低饱和灰蓝 |
| primary | `--primary` | `bg-primary` / `text-primary` | hsl(210 100% 60%) | 冷蓝主色，用于 CTA、薪资数字、激活态 |
| primaryForeground | `--primary-foreground` | `text-primary-foreground` | hsl(0 0% 100%) | 主色上的纯白文字 |
| accent | `--accent` | `bg-accent` | hsl(215 22% 20%) | hover/focus 浅底、选中态、菜单项背景 |
| accentForeground | `--accent-foreground` | `text-accent-foreground` | hsl(210 25% 85%) | accent 上的文字与图标 |
| border | `--border` | `border-border` | hsl(215 18% 24%) | 卡片、输入框、菜单边界，低对比细线 |

**语义色提示**: 
- 成功（高薪/正向增长：hsl(170 70% 50%) — bg: hsl(170 50% 15%) / border: hsl(170 60% 30%) / text: hsl(170 70% 65%)，青绿色系与主冷蓝色温一致
- 警告（中薪/注意）：hsl(38 90% 62%) — bg: hsl(38 50% 15%) / border: hsl(38 70% 35%) / text: hsl(38 90% 70%)，暖琥珀作为对比点缀，饱和度与 primary 对齐
- 错误（低薪/风险）：hsl(0 75% 60%) — bg: hsl(0 40% 15%) / border: hsl(0 60% 30%) / text: hsl(0 80% 70%)，低饱和红，不刺眼
- 图表系列色：primary 冷蓝 + 青蓝 hsl(190 90% 60%) + 紫蓝 hsl(250 70% 65%) + 青绿 hsl(170 70% 50%) + 琥珀 hsl(38 90% 62%)，均保持中高饱和、冷调为主

## 4. 字体与节奏

- **font-display**: Space Grotesk —— 几何感强的无衬线字体，略带科技机械感，用于大标题与薪资数字突出数据仪表气质
- **font-body**: Noto Sans SC —— 现代无衬线，中文阅读清晰，商务简约
- **数字字体**: IBM Plex Mono —— 等宽字体用于薪资区间、排名数字、图表数值，强化数据精密感
- **字号**: H1 text-4xl ~ text-5xl md:text-6xl（数字特大）；H2 text-2xl ~ text-3xl；body text-base；muted text-sm。
- **圆角**: 中 (rounded-md) —— 克制圆角，商务专业不圆润

## 5. 全局布局契约

- **Reference Layout Use**: 按需求结构推导，首屏薪资计算器为核心，下方三模块纵向分区
- **Page / Section Order**: 导航 → 首屏薪资预测计算器 → 技能提升规划器 → 城市与岗位决策助手 → 数据可视化看板 → 页脚
- **Standard Content Zone**: `max-w-6xl` + `mx-auto`，桌面端宽敞但不空旷，适配工具与数据看板平衡
- **Shell / Frame Alignment**: 顶部导航与内容区同宽对齐，导航背景延伸至视口两侧
- **Padding & Rhythm**: `px-4 md:px-6 lg:px-8 py-12 md:py-20`，section 间距 `py-16 md:py-24`
- **Full-bleed Zones**: 首屏背景渐变光晕、数据看板背景网格可全宽，内部卡片与文字受内容区约束
- **Local Narrowing**: 薪资预测表单收窄至 `max-w-3xl` 居中，决策助手双列布局
- **Overflow Strategy**: 数据看板图表容器 `overflow-x-auto`，城市排行表格横向滚动
- **Flexibility Boundary**: 允许移动端 padding、卡片内边距、图表列数可微调；全局 max-w、圆角、主色、阴影语言保持一致

## 6. 视觉与动效

- **装饰**: 细点阵网格底纹 + 径向渐变光晕 + 微光粒子
- **阴影/边界**: 轻 —— 卡片用 subtle 内发光边框 + 1px 边界，hover 时轻微上移 + 光晕增强
- **动效**: 精致克制 —— 表单输入实时校验微动画、薪资数字滚动出现、卡片悬停 0.2s 缓动、预测结果数字递增动画、图表入场淡入上移

## 7. 组件原则

- 按钮、表单、菜单、卡片必须有 Default / Hover / Active / Focus-visible / Disabled 状态
- Primary 承担预测、提交等主行动；Outline 用边界+浅底；Ghost 与菜单项用 accent 承接 hover/focus/selected
- 薪资数字结果使用等宽字体 + 渐变文字（primary 到青蓝），作为视觉焦点
- 技能标签多选：未选中态浅底边框，选中态 primary 填充 + 勾选图标
- 滑块控件：滑块轨道 accent 色，滑块柄 primary 色，带光晕
- 加载与空状态延续深蓝底 + 网格纹 + 等宽占位图形，不回退默认样式

## 8. Image Direction

- **Image Role**: 首屏背景氛围图 + 各分区章节头图（装饰性）
- **Image Art Direction**: 抽象数据可视化风格的深蓝科技背景，以细密的数据流、节点连线、光点粒子为元素，暗调低对比度，作为页面内容可读为前景文字服务。构图上暗下亮的径向渐变光晕，中心亮四周暗，模拟数据仪表的沉浸感。材质为磨砂玻璃质感的半透明数据图层叠在深蓝夜幕。情绪冷静、精密、未来感。
- **Image Prompt Keywords**: 深蓝色数据可视化背景, 抽象数据流节点连线, 细密光点粒子浮动, 径向渐变光晕中心亮, 暗调低对比度, 磨砂玻璃质感, 科技仪表氛围, 极简几何网格, 冷色调商务高级感, 3D渲染细腻质感
- **Image Avoidance**: 避免商务人物握手素材图、避免廉价霓虹赛博朋克高饱和紫粉、避免无意义抽象渐变blob、避免卡通插画风格、避免中文大字标语式海报构图

## 9. Anti-patterns

- **Split personality**: 页面之间切换深浅主题、圆角或阴影语言；全站共享同一套深蓝数据仪表系统。
- **Phantom tokens**: 编造 shadcn/ui 不存在的 CSS 变量；只使用已定义 token 或在主题里补齐。
- **Default SaaS drift**: 回到默认浅蓝白背景 + 紫色渐变的通用 SaaS 风；用深蓝基底 + 等宽数字 + 网格底纹建立本产品识别。
- **Invisible interaction**: hover 做了 focus-visible 丢了；每个可交互元素都要有键盘可见的光晕环状态。
- **Mono-hue tyranny**: primary 铺满按钮、tab、icon、边框、链接、图表；按 65-25-10 把 primary 收回到 CTA 与关键数字，其余交 accent / 中性色。
- **Status color drift**: 成功/警告/错误饱和度过高刺眼；语义色饱和度与 primary 对齐 ±15%，保持冷调统一。
